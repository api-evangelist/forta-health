# Forta Health

> Forta Health operates the largest virtual Applied Behavior Analysis (ABA) network in the United
> States, delivering autism therapy to children through Virtual ABA over a HIPAA-secure telehealth
> platform across 43 states and In-Home ABA in Dallas, Houston and San Antonio, Texas. Founded in
> 2021, Forta pairs Board Certified Behavior Analysts (BCBAs) with Registered Behavior Technicians
> and trained parents, using proprietary software and machine-learning models to personalize each
> treatment plan.

This file is generated by API Evangelist from public sources. Forta Health does not publish an

## Important context

- **Forta Health is not Forta Network.** The blockchain security project at forta.network /
  docs.forta.network is an unrelated company that shares the name.
- **There is no public developer program.** Forta Health publishes no API documentation, no
  developer portal, no SDKs and no self-serve API signup. The API described below is a private
  internal backend; its OpenAPI description happens to be served publicly at the API host root.
- **Every data operation is authenticated.** Only the health check answers anonymously.
